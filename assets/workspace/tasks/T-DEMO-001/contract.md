# T-DEMO-001 · 资料比较合同（DRAFT）

| 字段 | 内容 |
|---|---|
| 目标 | 比较 A、B 两份演练说明，给用户一个可核查的差异表 |
| 非目标 | 不评价真实产品；不联网、不安装、不联系、不删除、不发布 |
| 输入 | inputs/A.md 与 inputs/B.md；只读，不补造来源 |
| 输出 | outputs/comparison.md：比较表、结论、信息缺口 |
| 处理位置 | 使用哪个模型/工具服务尚须确认；已有会话授权仅限已提供内容 |
| 外部动作 | 禁止；用户取得草稿即为预定交付边界 |
| 执行上限 | max_attempts=2；max_review_rounds=2；max_parallel=1 |
| 授权引用 | PENDING；由真实用户指令或既有有效授权确定 |

| 验收编号 | 条件 | 方法 |
|---|---|---|
| AC-01 | 保留原件、输出形式、验收方式三个维度齐全 | 与 A1–A3、B1–B3 对照 |
| AC-02 | 关键陈述指向输入条目 | 检查每项来源定位 |
| AC-03 | B 的摘要验收方式写“未说明”，不臆造 | 反查 B3 |
| AC-04 | 不声称任何外部联络、部署或真实使用效果 | 检查产物和操作记录 |

执行者可起草；不能为通过验收删除 AC-03。
