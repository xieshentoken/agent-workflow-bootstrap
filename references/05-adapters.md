# 05 · 适配器与渐进自动化

## 不变层与可换层

任务、授权、状态、验收与交接属于中立协议。
调用模型、读写文件、接消息、调工具、限制权限属于适配实现。
不因换工具改变合同、预算和许可。工具缺能力时改人工或阻塞，不偷偷放宽约束。

| 能力 | 需要的证明 | 不具备时 |
|---|---|---|
| 保存文件 | 指定位置实际文件及读取结果 | 给完整文本，由人保存 |
| 只读输入与受限写入 | 真实权限配置及非敏感测试结果 | 只做人工监督或只读任务 |
| 输入和输出版本 | 可定位的版本、哈希或记录号 | 手工冻结版本 |
| 来源身份 | 宿主或服务校验，而非消息自称 | 不触发有副作用动作 |
| 停止当前执行 | 真实停止测试与在途检查 | 不承担无人值守 |
| 副作用确认 | 真实回执和查询能力 | 人执行或 UNKNOWN 阻塞 |
| 成本限制 | 服务上限或准确计量证据 | 写费用未知；用可观测限额，不能称硬封顶 |

## 可选 DSH 路径

只有用户明确选它，且任务确实围绕一个 GitHub 仓库时，才考虑 dsh-superagent。
核对该版本的 README、SETUP、部署说明及依赖；不能把本包日期固定的版本要求当成未来恒定条件。
本轮只静态阅读，不提供“已验证可部署”保证。

特别核查：worker 以宿主操作系统用户运行；命令包装不是安全隔离；合并条件主要在提示词，仓库规则另配；observe 不阻止明确请求；暂停不必然打断正在运行的轮次。
采用独立账号/配置有助于归属和降低混用，但不等于真正权限隔离。
不照抄自动修复调度。创建常驻服务和定时器属于独立实施范围，用户须知道如何停用。

## M2 最小运行时施工顺序（规划，不是本包已实现）

| 顺序 | 组件 | 验收 |
|---|---|---|
| 1 | 一个已鉴权入口，把事件转中立字段 | 非允许发送者不触发；重复事件不重复建任务 |
| 2 | 单写者状态存储与队列 | 重启保持状态；并发不能重复领同一动作 |
| 3 | 确定性准入 + 可选模型研判 | 模型不能改授权；无规则时不自主开始 |
| 4 | 一个受限执行适配器 | 任务边界、数据出口和预算实际生效 |
| 5 | 独立验收与交付核实 | 没有证据不能 DONE；UNKNOWN 不自动重发 |
| 6 | 待决/故障界面与停止入口 | 人能定位、暂停、终止、撤权及恢复 |

持久存储、幂等、身份、权限、停止等属于程序/运行环境职责，不适合只写在提示词里。
技能负责引导人和 Agent 实现并验证这些组件，不代替组件本身。
